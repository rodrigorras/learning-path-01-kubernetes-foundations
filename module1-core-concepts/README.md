# Module 1 — Kubernetes Architecture & Core Concepts

Welcome to Module 1 of the Kubernetes Foundations course!

This module introduces the architectural pillars that make Kubernetes unique: declarative configuration, YAML manifests, and the self-healing reconciliation loop.

## Chapters

*   [Chapter 3 — Imperative vs. Desired State, YAML Manifests & The Reconciliation Loop](chapter-3-imperative-vs-declarative/README.md)

### What you will learn:
* **Imperative vs. Declarative Operations:** Why Kubernetes moves away from manual operational commands in favor of desired state.
* **YAML Manifest Structure:** Breaking down `apiVersion`, `kind`, `metadata`, and `spec`.
* **Declarative Pod Deployments:** How `kubectl apply` manages object lifecycles and configuration drift.
* **The Reconciliation Loop:** How the Kubernetes control plane continuously detects differences between current state and desired state to deliver automatic self-healing.
