# Chapter 1 — Local Kubernetes Options

Choose and set up a local Kubernetes cluster tailored to your operating system, resource constraints, and development workflow.

## Sections

*   [Installing Kind](installing-kind/README.md)  
    *Run local Kubernetes clusters using Docker container "nodes". Fast, lightweight, and ideal for multi-node testing and CI pipelines.*

*   [Installing Minikube](installing-minikube/README.md)  
    *The classic local Kubernetes tool supporting various VM drivers and container runtimes, complete with built-in add-ons.*

*   [Installing Docker Desktop](installing-docker-desktop/README.md)  
    *A turnkey desktop solution providing a single-node Kubernetes cluster with simple UI controls for macOS and Windows.*
