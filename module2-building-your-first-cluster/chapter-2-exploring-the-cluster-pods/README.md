# Chapter 2 — Exploring the Cluster: Pods

A tutorial based on the commands executed in the video walkthrough.

---

## Prerequisites

Access to a Kubernetes cluster with `kubectl` configured.

---

## Step 1: List Pods in a Specific Namespace

To view all the pods running within a particular namespace, use the `kubectl get pods` command followed by the namespace flag:

```bash
kubectl get pods -n <namespace-name>
```

---

## Step 2: Access an Interactive Shell Inside a Pod

To log into a running container inside a pod and execute commands directly:

```bash
kubectl exec -it <pod-name> -n <namespace-name> -- /bin/sh
```

Once inside, you can run commands like `ps` to check running processes or inspect local files.

Type `exit` to exit the container shell.

---

## Step 3: View Container Logs

To check the logs generated by a specific pod:

```bash
kubectl logs <pod-name> -n <namespace-name>
```

---
