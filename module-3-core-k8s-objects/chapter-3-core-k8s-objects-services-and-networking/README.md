# Chapter 3 — Core Kubernetes Objects: Services & Networking

Explore how Kubernetes Services provide stable networking, DNS resolution, and load balancing across dynamic Pods. This chapter demonstrates configuring ClusterIP, NodePort, and LoadBalancer services using both declarative manifests and imperative commands.

## Sections

*   [Declarative Management](declarative/README.md)  
    *Define, configure, and maintain Services and Endpoints declaratively using version-controlled YAML manifests.*

*   [Imperative Management](imperative/README.md)  
    *Quickly expose workloads, configure port mappings, inspect endpoints, and troubleshoot connectivity directly using `kubectl` CLI commands.*
