# Chapter 2 — Core Kubernetes Objects: Deployments & ReplicaSets

Explore how to manage scalable, self-healing containerized workloads using Kubernetes Deployments and ReplicaSets. This chapter demonstrates managing application lifecycles, rollout revisions, and rollbacks using both declarative manifests and imperative commands.

## Sections

*   [Declarative Management](declarative/README.md)  
    *Manage Deployments and ReplicaSets declaratively with version-controlled YAML manifests, tracking rollout revisions via annotations and rolling back changes.*

*   [Imperative Management](imperative/README.md)  
    *Execute lifecycle operations directly using `kubectl` CLI commands to create deployments, scale replicas, test self-healing, update container images, and roll back revisions.*
